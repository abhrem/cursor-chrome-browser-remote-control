Connect the bridge

  1. Reload Cursor after the bridge is in MCP settings. Cursor starts it on 127.0.0.1:39221.
  2. Open cursor-chrome/bridge/.token. That file is the pairing token.
  3. Paste the token below and click Connect.

The bridge is the local link between Cursor and this extension. Cursor sends a command to the bridge, and the extension runs it in Chrome. The token is how they recognize each other.

Paired with the local bridge.

Cursor talks to the bridge on this computer. This extension picks up those commands and runs them in Chrome.
